# Prose

"Carnet de route" article typography for club news and ride reports, applied to rich text with one class.

- **Source:** `app/globals.css` `.prose` (and `.prose-sm`, `.prose-editor` for the admin WYSIWYG). Outside the app use `.bl-prose`.
- **Type:** `prose-body` 1.0625rem / 1.72 in `text-body`; `prose-h1` and `prose-h2` semiwide; h2 carries a hairline `rule` above it.
- **Details:** square list markers in `brand`; links `brand-strong` (brand-soft by night) with a 40% red underline; blockquote with a 1px ink rule and italic; `hr` is a dashed scale strip; images get a 1px `rule` frame.
- **Rules:** French typography: non-breaking space before `:` `;` `!` `?` and units, « guillemets » for quotes. Keep paragraphs to 65–75ch.
