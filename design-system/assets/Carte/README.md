# Carte

The ten layers of the club territory: a 32 km square centred on the Place de la Féchère (50.62302, 4.64223), each a 3200×3200 SVG used as a CSS mask and tinted by its `map-*` token, so the same sheet prints by day and by night.

| File | Token | Layer |
|---|---|---|
| `woods.svg` | `map-woods` | Woods (Bois de Buis…) |
| `lakes.svg` | `map-lake` | Lakes and ponds |
| `relief.svg` | `map-contour` | 5 m contours |
| `relief-index.svg` | `map-contour-index` | Index contours |
| `water.svg` | `map-water` | Rivers (the Dyle) |
| `roads-tertiary.svg` | `map-road-tertiary` | Lanes |
| `roads-secondary.svg` | `map-road-secondary` | Secondary roads |
| `roads-primary.svg` | `map-road-primary` | Primary roads |
| `roads-major.svg` | `map-road-major` | Major roads |
| `rail.svg` | `map-rail` | Railway |

Stack them in this order. Repository copies: `public/carte/` (classes `.carte-*` in `app/globals.css`), generated by `scripts/generate-territory-map.mjs` from AWS Terrain Tiles and OpenStreetMap data. In `<img>` they render as flat black shapes: use them as masks.
