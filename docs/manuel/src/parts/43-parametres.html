Qui est le propriétaire du site

Un administrateur dont l'adresse de courriel a été désignée lors de la mise en place du site. Ce n'est pas un rôle que l'on attribue dans le back-office. Pour changer de propriétaire, il faut s'adresser à la personne qui gère l'hébergement.

21.1Qui peut ouvrir la page

Seul le propriétaire du site voit les réglages. Un autre administrateur (président, webmaster…) voit l'entrée Paramètres dans le menu, mais la page lui répond par un message.

Les responsables qui ne sont pas administrateurs (trésorier, secrétaire, capitaine) n'ont jamais accès à cette page, même avec des accès supplémentaires.

Bon à savoir

Le tableau de bord propose aussi un raccourci Paramètres & Thème à tous les administrateurs : il mène à la même page, donc au même message pour ceux qui ne sont pas propriétaires.

21.2Choisir le thème clair, sombre ou automatique

Le thème est l'apparence du site public : papier clair le jour, fond sombre le soir. Le choix est personnel : il est mémorisé dans votre navigateur, sur cet ordinateur. Il ne change rien pour les autres visiteurs et chacun peut régler le sien. L'administration reste toujours en mode clair, quel que soit votre choix.

  1. Cliquez sur Paramètres dans le menu de gauche.
  2. Dans la section Apparence & thème visuel, cliquez sur la carte de votre choix : Mode Clair, Mode Sombre ou Automatique.Un petit repère Actif marque la carte choisie.
  3. Regardez l'Aperçu en direct du thème plus bas : une maquette de la page d'accueil prend aussitôt l'apparence choisie.
ChoixEffet sur le site public, pour vous seulement

Résultat sur le site

Votre navigateur affiche le site public dans le thème choisi, tout de suite. Les autres personnes ne voient aucun changement. Si vous utilisez un autre ordinateur ou un autre navigateur, le choix est à refaire.

La carte Retours & captures d'écran décide si le bouton Donner un avis (chapitre 19, page ) apparaît sur le site, et pour qui.

Procédure : permettre à tous les membres connectés d'envoyer des retours

  1. Ouvrez Paramètres et descendez jusqu'à la carte Retours & captures d'écran.
  2. Dans le bloc Connexion GitHub, vérifiez que la clé est enregistrée. Si la phrase rouge « Aucun jeton GitHub : les retours ne peuvent pas être envoyés. » est affichée, commencez par 21.4.
  3. Cochez Activer les retours visuels.La notification « Retours activés. » s'affiche. Le réglage est enregistré tout de suite, sans bouton à valider.
  4. Sous Qui voit le bouton ?, choisissez Membres connectés.
Résultat sur le site

Le bouton rouge Donner un avis apparaît en bas à gauche de toutes les pages (y compris l'administration) pour le public choisi. Pour couper l'outil, décochez la case : le bouton disparaît pour tout le monde.

Attention · jusqu'à une minute de décalage

Le site garde la réponse en mémoire pendant 60 secondes dans chaque navigateur. Une personne qui a déjà la page ouverte voit donc le bouton apparaître ou disparaître avec jusqu'à une minute de retard, ou après avoir rechargé la page. Pour vérifier votre réglage, ouvrez le site dans une fenêtre de navigation privée ou attendez une minute.

Attention · le texte sous l'interrupteur ne change pas

La phrase « Désactivé : aucun code de retour n'est chargé chez les utilisateurs. » reste affichée sous l'interrupteur même quand l'outil est allumé. C'est un défaut d'affichage : fiez-vous à la case cochée et à la notification « Retours activés. ».

Attention · l'outil peut être coupé depuis l'hébergement

Si l'outil a été coupé au niveau de l'hébergement du site, la carte affiche « NEXT_PUBLIC_FEEDBACK_ENABLED=false : l'outil est coupé globalement. » et l'interrupteur est grisé. Dans ce cas, seule la personne qui gère l'hébergement peut le rallumer.

21.4Enregistrer ou retirer la clé de connexion GitHub

Pour publier les retours sur GitHub (le site public décrit au chapitre 19), le site a besoin d'une clé de connexion au compte GitHub du club. Cette clé est un long texte qui commence par « github_pat_ ». Elle est vérifiée, puis enregistrée de façon chiffrée ; elle n'est jamais réaffichée, seuls les quatre derniers signes le sont.

Ce qui est écrit dans le blocCe que cela veut dire
« Aucun jeton GitHub : les retours ne peuvent pas être envoyés. Collez-en un ci-dessous. »Aucune clé n'est enregistrée. L'outil ne peut pas fonctionner.
« Jeton enregistré (…a9Fz) le 26/11/2026. »Une clé a été collée ici ; ses quatre derniers signes et la date sont rappelés.
« Jeton fourni par le serveur (…xxxx). Un jeton collé ici ne sert que si cette variable disparaît. »La clé est déjà installée au niveau de l'hébergement du site. Elle est prioritaire sur celle que vous colleriez ici.

Procédure : enregistrer une clé

  1. Demandez la clé à la personne qui l'a créée sur GitHub, ou créez-la avec elle (voir l'encadré ci-dessous).
  2. Dans le bloc Connexion GitHub, cliquez dans le champ Jeton GitHub (il s'appelle Remplacer le jeton si une clé existe déjà).
  3. Collez la clé (Ctrl + V). Le texte reste masqué.
  4. Cliquez sur Tester et enregistrer. Le bouton ne s'active que lorsque le texte fait au moins 20 caractères.Le site essaie la clé sur GitHub avant de la garder. Notification en cas de succès : « Jeton GitHub enregistré et testé. »

Pour la retirer : cliquez sur Supprimer le jeton (ce bouton n'existe que si une clé est enregistrée). Aucune confirmation n'est demandée. Notification : « Jeton GitHub supprimé. ».

Message d'erreurCe que cela veut dire
Ce n'est pas un jeton GitHub valide.Le texte collé n'a pas la bonne forme. Recopiez-le en entier, sans espace.
GitHub refuse ce jeton (invalide ou expiré).La clé est fausse ou a expiré : il en faut une nouvelle.
Ce jeton n'a pas accès au dépôt …La clé n'a pas été limitée au bon dépôt ou n'a pas les bons droits.
GitHub est injoignable depuis le serveur.Problème passager : réessayez plus tard.
Stockage impossible : …Un réglage technique de l'hébergement manque. Prévenez la personne qui gère l'hébergement.
Comment la clé est créée sur GitHub

Sur le site de GitHub, page « Personal access tokens », on crée une clé « à granularité fine », limitée au seul dépôt du club, avec les droits Issues et Contents en lecture et en écriture. Cette opération se fait avec le compte GitHub du club : si vous n'y êtes pas à l'aise, faites-la avec la personne technique.

Attention · jamais par courriel ni sur papier

Cette clé donne accès au dépôt du club. Ne la copiez pas dans un courriel, un message ou un document partagé : collez-la directement dans le champ, puis supprimez le texte copié. Si le secret des sessions du site est changé par l'hébergeur, la clé enregistrée devient inutilisable : il faut la coller de nouveau.

Résultat sur le site

Avec une clé valide, le bouton Donner un avis peut envoyer des retours et la page Retours visuels peut les lire (jusqu'à une minute après l'enregistrement). Sans clé, l'envoi échoue avec le message « Les retours ne sont pas encore configurés côté serveur. » et la liste des responsables affiche « Jeton GitHub manquant… ».

Ne vous fiez pas à cette page pour connaître la saison en cours.
