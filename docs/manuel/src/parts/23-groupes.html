Cet écran ne change que la façon dont les groupes sont nommés à l'affichage. Les codes enregistrés dans les fiches (A, B, BC, C, VTT…) ne changent jamais : renommer ou rassembler des groupes ne modifie aucun historique, et chaque rassemblement peut être défait.

Les vitesses, les distances et les couleurs des groupes ne se règlent pas ici : elles sont fixes. Si elles doivent changer, demandez au webmaster.

12.1Comprendre l'écran

Cliquez sur Groupes & Pelotons dans le menu de gauche, rubrique Gestion du club. Le bloc « Légende des groupes » affiche une ligne par groupe, de haut en bas dans l'ordre où les groupes apparaissent partout sur le site (filtres, légendes, statistiques).

N°ÉlémentÀ quoi ça sert
1Flèches Monter / DescendreChangent la place du groupe dans la liste, donc dans tous les filtres et légendes.
2CodeLe code enregistré dans les fiches (A, B, BC, C, VTT…). Il est fixe pour un groupe existant. Il n'est modifiable que pour un groupe que vous venez d'ajouter (12 caractères au plus).
3Nom affichéLe nom que voient les gens (24 caractères au plus, unique). Exemple : GR1.
4Nombre de fichesCombien de fiches utilisent ce code : membres qui l'ont choisi comme groupe préféré, et lignes du classement. C'est une information, pas un réglage.

6Nouveau codePour ajouter un groupe (par exemple D).

8Aperçu des étiquettesRappelle le résultat sous la forme « B → GR2 » pour chaque groupe.

Un groupe peut aussi porter des pastilles Codes fusionnés (section 12.4). Le compteur « N / 12 groupes » rappelle que la liste est limitée à 12 groupes.

12.2Passer aux noms GR1 à GR4

Le club roule désormais en quatre groupes route et un groupe VTT. Pour adopter les noms GR1, GR2, GR3, GR4 et VTT, le plus simple est d'utiliser la proposition toute faite.

  1. Ouvrez Groupes & Pelotons.Tant que les noms ne correspondent pas à la proposition, un bloc « Proposition de regroupement » s'affiche en haut.
  2. Lisez la proposition : A (avec A- et A+) devient GR1, B devient GR2, BC devient GR3, C devient GR4, VTT reste VTT. Le nombre de fiches concernées est indiqué à droite de chaque groupe.
  3. Cliquez sur Appliquer la proposition.Le message « Proposition appliquée. Renommez les groupes si besoin, puis enregistrez pour la mettre en ligne. » s'affiche. Rien n'est encore en ligne.
  4. Si besoin, corrigez un Nom affiché.
  5. Vérifiez l'Aperçu des étiquettes.
  6. Cliquez sur Enregistrer les groupes.Le message « Noms des groupes enregistrés. Ils sont visibles partout sur le site. » s'affiche.
Exemple

Une fois la proposition appliquée, l'« Aperçu des étiquettes » affiche « A → GR1 », « B → GR2 », « BC → GR3 », « C → GR4 » et « VTT → VTT ». Un membre qui a choisi le groupe B dans sa fiche est affiché « GR2 » partout.

Résultat sur le site

Les nouveaux noms apparaissent immédiatement partout, sans attendre (section 12.6). Aucune donnée n'est perdue : les anciens codes restent dans les fiches.

12.3Renommer, déplacer, ajouter, retirer un groupe

Renommer un groupe

  1. Dans la ligne du groupe, cliquez dans Nom affiché et tapez le nouveau nom.
  2. Cliquez sur Enregistrer les groupes.

Changer l'ordre

Cliquez sur la flèche Monter ou Descendre de la ligne, puis enregistrez. La flèche est grisée aux extrémités de la liste.

Ajouter un groupe

  1. Dans la zone grise en bas de la liste, tapez le code dans Nouveau code (par exemple D).
  2. Cliquez sur Ajouter le groupe.Une nouvelle ligne apparaît. Donnez-lui un Nom affiché.
  3. Enregistrez.

Sous la liste, le site peut aussi signaler des codes « trouvés dans les fiches mais rattachés à aucun groupe ». Chacun apparaît sur un bouton + code · N : cliquez dessus pour l'ajouter comme nouveau groupe.

Retirer un groupe de la liste

Cliquez sur la corbeille de la ligne, puis enregistrez. Les fiches concernées n'ont rien perdu : elles s'affichent de nouveau avec leur code brut (par exemple « Groupe A »).

Attention

Le site refuse d'enregistrer et vous l'indique en rouge (« Erreur : … ») si : un code ou un nom est vide, deux groupes ont le même code ou le même nom, il y a plus de 12 groupes, ou un code est rattaché à plusieurs groupes. Corrigez la ligne signalée, puis enregistrez de nouveau.

12.4Rassembler des codes dans un groupe

Dans les anciennes fiches, un même groupe peut avoir plusieurs codes (A et A-, par exemple). En les rassemblant, ils sont comptés ensemble dans les statistiques et le classement.

  1. Dans la ligne du groupe d'arrivée (par exemple A), repérez la zone Codes fusionnés.
  2. Cliquez sur la liste + Fusionner un code… et choisissez un code (le nombre de fiches est indiqué).Cette liste ne propose que les codes présents dans les fiches et encore rattachés à aucun groupe.
  3. Le code apparaît en pastille. Enregistrez.

Pour défaire un rassemblement : cliquez sur la croix de la pastille (Détacher le code …), puis enregistrez. Les fiches ne sont jamais modifiées.

Résultat sur le site

Le classement, les statistiques et les décomptes regroupent les lignes des codes rassemblés (A et A- ensemble sous « GR1 »).

12.5Enregistrer ou annuler

Tant que vous n'avez pas cliqué sur Enregistrer les groupes, rien n'est modifié sur le site. Le bouton Annuler les modifications remet l'écran dans son état enregistré. Si vous quittez la page avec des modifications en cours, votre navigateur vous demande de confirmer.

Attention

Un changement de nom concerne tout le monde, tout de suite : membres, visiteurs et autres responsables. Prévenez les capitaines avant de renommer.

12.7GR2+ et GR2− dans le sondage

Dans le sondage du week-end, quand une personne choisit le groupe B (GR2), le site lui propose deux variantes :

  • GR2+ : même parcours que GR1 (le plus long).
  • GR2− : parcours plus court.

Le nom affiché est le nom court du groupe B, suivi de « + » ou de « − ». Si vous renommez le groupe B en « GR2 », les variantes s'appellent « GR2+ » et « GR2− ».

Bon à savoir

Ces variantes ne se règlent pas dans cet écran : elles sont fixes. On les retrouve à côté du groupe dans la page d'un sondage du back-office et dans l'export WhatsApp (chapitre 4, page ).
